# Política de segurança

Não publique em issues dados pessoais, CPFs, e-mails, credenciais, endereços internos ou logs de produção.

Para relatar uma vulnerabilidade, encaminhe de forma privada:

- versão do Moodle e do plugin;
- passos mínimos para reprodução;
- impacto observado;
- método de inscrição envolvido;
- mensagens de erro sem dados pessoais.

Reproduza problemas somente em ambiente de homologação.
