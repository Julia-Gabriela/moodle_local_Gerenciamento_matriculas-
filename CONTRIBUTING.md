# Como contribuir

1. Crie uma branch a partir da branch principal.
2. Preserve o componente `local_gerenciamentomatriculas` e o diretório de instalação `gerenciamentomatriculas`.
3. Não inclua dados reais de alunos, CPFs, e-mails ou logs de produção.
4. Execute a validação de sintaxe PHP e JavaScript.
5. Teste a instalação e as operações em um Moodle de homologação.
6. Abra um pull request descrevendo a alteração e os testes realizados.

Mudanças em permissões, confirmação, locks, limites, processamento em blocos ou validações devem ser tratadas como alterações de segurança.
